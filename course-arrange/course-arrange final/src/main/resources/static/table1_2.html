⚡ NP-Hard Nature

Course timetabling is proven to be NP-hard, meaning there is no known polynomial-time algorithm to find optimal solutions. The search space grows exponentially with problem size, making exhaustive search impossible for realistic instances.

🎯 Heuristic Approach Required

Due to complexity, we use Genetic Algorithm (GA) which explores the solution space probabilistically. AMOGA adapts parameters dynamically to improve convergence and solution quality.

📈 Constraint Satisfaction

Hard constraints must be satisfied first (fitness ≥ 100). Soft constraints then optimize quality. The algorithm prioritizes feasible solutions before optimization.

📊 Multi-Objective

Multiple objectives compete: minimize conflicts, maximize preferences, balance resources. The adaptive fitness function balances these competing goals effectively.
