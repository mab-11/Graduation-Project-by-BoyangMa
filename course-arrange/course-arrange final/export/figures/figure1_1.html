CONSTRAINT OPTIMIZATION
HARD CONSTRAINTS
  • One class, one course at same time
  • One teacher, one course at same time
  • One room, one course at same time
  • Room capacity >= Class size
  • Room type matches course type
SOFT CONSTRAINTS
  • Teacher time preferences
  • Course concentration (adjacent)
  • Room balance utilization
  • Day concentration
  • Room type preference
OBJECTIVE FUNCTION
  • Maximize soft>Minimize hard constraint satisfaction
  • Maximize resource utilization
  • Balance workloads
  • Maximize overall fitness
🎯 SOLUTION APPROACH
Adaptive Multi-Objective Genetic Algorithm (AMOGA)

Encoding: Chromosome [timeslot, room] pairs for each task
Selection: Tournament selection with elitism
Crossover: Uniform crossover (pc=0.85)
Mutation: Adaptive mutation rate (pm=0.01~0.3)
Fitness: Multi-objective with penalty and reward
